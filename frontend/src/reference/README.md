vietnam-divisions.json is derived from data/tinh.json and data/xa.json:
only province codes/names and child ward codes/names are retained.
34 provinces/cities and 3,321 communes/wards/special zones; no district level.
This is a bundled snapshot, not a live automatic update feed. To refresh, download
the source again, join wards by ma_tinh, and verify counts and parent relationships.
meta.json preserves the upstream source metadata.
